01 / The loop

Three commands.
One growing collection.

Every session is short, deliberate, and saved between invocations. Make a choice, see what the wild gives back, then decide what stays.

01
◌

Hunt the unknown

Run hunt to generate one wild encounter. A successful hunt grants 5 XP and replaces the pending encounter.

15 second cooldown
02
◉

Choose your angle

Pick a ball that fits the moment. Type, speed, time of day, ownership, and stats can all change the odds.

11 ball types
03
✦

Build your dex

Catch to earn XP, unlock better supplies, and see your collection grow. Sell surplus catches when you need a refill.

local save file

04 / Your terminal

Small setup.
Big collection.

PokéCatch runs locally on Python 3.12+. Install it with pipx, then start with a clean inventory and 50 Poké Balls.

✓ Python 3.12+✓ Saves to ~/.pokecatch✓ Open source game loop
pipx install pokecatch-cli-game
pokecatch hunt
Wild encounter found.
pokecatch catch pb
Catch attempt resolved.
